# MButton

A clickable element that triggers an action. Supports six visual modes, three sizes, icon slots before/after the label, and a disabled state.

## Modes

| Mode | When to use |
|------|-------------|
| `primary` | Main call-to-action — highest emphasis |
| `secondary` | Secondary action |
| `tertiary` | Low-emphasis action |
| `outlined` | Outlined style with visible border |
| `transparent` | Ghost button, no background |
| `round` | Icon-only circular button (FAB) |

## Customization

MButton is styled with CSS variables. See **Guides/Theming & Customization** for the
override mechanism (global / zonal / instance). Below is the component's public token API.

**Geometry — component tokens** (override per-component; default falls to a semantic role):

| Token | Controls | Default |
|-------|----------|---------|
| `--button-radius` | Corner radius (all modes except `round`) | `--radius-control` · outlined: `--radius-control-sm` |
| `--button-radius-round` | `round` mode radius | `50%` |
| `--button-gap` | Gap between icon and label | `--gap-control` |
| `--button-px` | Horizontal padding | `--padding-control-x-{s,m,l}` |
| `--button-py` | Vertical padding | `--padding-control-y-{s,m,l}` |
| `--button-font-size` | Label size | `--font-size-{sm,md,lg}` |
| `--button-icon-size` | `round` width/height | `--size-control-{s,m,l}` |
| `--button-icon-padding` | `round` inner padding | `--padding-icon-{s,m,l}` |

**Colors & focus** are bound to global semantics (retune once, all controls follow — no
per-button token by design): `--color-action-*` families, and `--focus-ring-width` /
`--focus-ring-offset` / `--color-focus-ring`.

```css
/* square, tighter buttons everywhere */
:root {
  --button-radius: var(--radius-2);
  --button-gap: var(--space-2);
}

/* recolor by retuning the PALETTE — action colors reference it, so every button
   (and link, etc.) follows. Never hardcode a raw value into a semantic token. */
:root[data-brand="acme"] {
  --palette-primary-700: #5b21b6;  /* → --color-action-rest  */
  --palette-primary-600: #6d28d9;  /* → --color-action-hover */
}
```
