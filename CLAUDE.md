# WS-UIKit — instructions for Claude

Мультибрендовый React-компонентный кит. Главный инвариант: **кит полностью
перебрендивается через CSS** — подключением набора токенов, без правки компонентов и без
JS-темизации.

## Стилизация — читай `CONTRIBUTING.md` перед правкой стилей

Полные правила и чек-лист — в [CONTRIBUTING.md](CONTRIBUTING.md). Коротко, жёсткие инварианты:

1. **Четыре слоя токенов**, ссылки только вниз:
   `компонент → --_private → --<comp>-* → semantic → primitive`.
   Компоненты НЕ ссылаются на primitive (`--space-N`, `--radius-N`) напрямую — только на семантику
   (`--gap-control`, `--radius-control`, `--color-action-*`).
2. **Всё через `var()`-шов, включая структуру** (`flex-direction`, `align-items`). Проп/класс задаёт
   дефолт (`--_flex-*`), публичный шов (`--flex-*`) остаётся свободным для бренда.
3. **В `src/**/*.tsx` (кроме `*.stories`/`*.test`) запрещено:** инлайн-стиль с финальным значением;
   заморозка скиннабельного значения проп-литералом во внутренней композиции. Стилизация — классами,
   задающими переменные.
4. **Тело компонента читает только свои `--<comp>-*`** (через `--_private`), не глобальную семантику
   напрямую — вся тематизируемая поверхность перечислима из `<Comp>.vars.css`.
5. Публичное имя `--<comp>-*`, приватное `--_*`. Снаружи трогают только публичные.
6. `*.stories.tsx` и клиентский код используют пропсы (`gap`, `variant`, `size`) свободно.

После правки стилей сверяйся с чек-листом нового компонента в конце CONTRIBUTING.md.
