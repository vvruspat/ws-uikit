MThemeSelector from ws-uikit. Use via `window.WsUikit.MThemeSelector` (bundle loaded from the root `_ds_bundle.js`). Wrap the tree in `<WsThemeProvider>` (full provider chain in README.md — components read theme/i18n from that context).

# Definition

A MThemeSelector is a component that allows you to choose a design theme: light or dark.
