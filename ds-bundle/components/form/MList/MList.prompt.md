MList from ws-uikit. Use via `window.WsUikit.MList` (bundle loaded from the root `_ds_bundle.js`). Wrap the tree in `<WsThemeProvider>` (full provider chain in README.md — components read theme/i18n from that context).

# Definition

A list can be used to display content related to a single subject.

The content can consist of multiple elements of varying type and size.
