# MInput

A text input field with support for labels, captions, icon slots (`before`/`after`), and three validation statuses.

## Overview

All statuses at a glance.

## Statuses

| Status | Description |
|--------|-------------|
| `regular` | Default, no validation feedback |
| `valid` | Input is valid — green accent |
| `invalid` | Input has an error — red accent |
